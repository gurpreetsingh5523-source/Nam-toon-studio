SECTION 1: EMAIL MASTERY (ਈਮੇਲ ਮਾਸਟਰੀ)
═══════════════════════════════════════════════════════════════════

📧 5 UNIVERSAL EMAIL PATTERNS (Generate ANY email):

Pattern 1: REQUEST (ਬੇਨਤੀ)
   Structure: Greeting → Context → Clear Ask → Deadline → Thanks
   Punjabi: "ਸਤ ਸ੍ਰੀ ਅਕਾਲ → ਮੈਨੂੰ X ਚਾਹੀਦਾ ਹੈ → ਕਿਰਪਾ ਕਰਕੇ → [date] ਤੱਕ → ਧੰਨਵਾਦ"
   English: "Dear [Name] → I need X → Could you please → by [date] → Thank you"

Pattern 2: UPDATE (ਅੱਪਡੇਟ)
   Structure: Summary → Progress → Next Steps → Questions
   Punjabi: "ਕੰਮ ਦੀ ਸਥਿਤੀ: → ਹੋ ਗਿਆ: X → ਅਗਲਾ: Y → ਸਵਾਲ: Z"
   English: "Update: → Completed: X → Next: Y → Questions: Z"

Pattern 3: RESPONSE (ਜਵਾਬ)
   Structure: Acknowledge → Answer → Action → Close
   Punjabi: "ਜੀ ਮੈਂ ਸਮਝ ਗਿਆ → ਜਵਾਬ: X → ਮੈਂ ਕਰਾਂਗਾ: Y → ਹੋਰ ਚਾਹੀਦਾ?"
   English: "Thank you for → Answer: X → I will: Y → Anything else?"

Pattern 4: APOLOGY (ਮੁਆਫ਼ੀ)
   Structure: Sorry → Reason → Fix → Prevention
   Punjabi: "ਮਾਫ਼ੀ ਚਾਹੁੰਦਾ ਹਾਂ → ਕਿਉਂਕਿ → ਹੁਣ ਠੀਕ ਕਰਾਂਗਾ → ਦੁਬਾਰਾ ਨਹੀਂ ਹੋਵੇਗਾ"
   English: "I apologize → because → I will fix → Won't happen again"

Pattern 5: CELEBRATION (ਖੁਸ਼ੀ)
   Structure: Great News → Achievement → Team Credit → Next Goal
   Punjabi: "ਬਹੁਤ ਵਧੀਆ ਖ਼ਬਰ! → ਅਸੀਂ ਕਰ ਲਿਆ → ਟੀਮ ਦਾ ਕਮਾਲ → ਹੁਣ ਅੱਗੇ"
   English: "Great news! → We achieved → Thanks to team → Next up"

💡 80/20 Rule: ਇਹ 5 patterns → 95% emails covered!

SECTION 3: PHONE CALL MASTERY (ਫ਼ੋਨ ਕਾਲ ਮਾਸਟਰੀ)
═══════════════════════════════════════════════════════════════════

☎️ CALL STRUCTURE (3-Part Framework):

Opening (ਸ਼ੁਰੂਆਤ):
   Punjabi: "ਸਤ ਸ੍ਰੀ ਅਕਾਲ ਜੀ, [name] ਬੋਲ ਰਿਹਾ ਹਾਂ। ਕਿਵੇਂ ਹੋ?"
   English: "Hello [name], how are you? I'm calling about..."

Body (ਮੁੱਖ ਗੱਲ):
   1. State purpose clearly
   2. Give context (2-3 sentences max)
   3. Ask specific question
   4. Listen actively

Closing (ਸਮਾਪਤੀ):
   Punjabi: "ਠੀਕ ਹੈ ਜੀ। ਫਿਰ ਗੱਲ ਕਰਾਂਗੇ। ਰੱਬ ਰਾਖਾ 🙏"
   English: "Thank you for your time. Talk soon. Take care!"

💡 Golden Rule: Keep calls under 5 minutes for efficiency

SECTION 4: PRESENTATION MASTERY (ਪ੍ਰੈਜ਼ੈਂਟੇਸ਼ਨ)
═══════════════════════════════════════════════════════════════════

🎤 PRESENTATION FORMULA (GPT-4 Compressed):

Structure: 
1. Hook (First 30 seconds): Shocking fact or question
2. Problem (1 minute): What's the pain?
3. Solution (2 minutes): Your idea
4. Proof (1 minute): Data/examples
5. Call to Action (30 seconds): What next?

Punjabi Style:
- Start: "ਸੁਣੋ ਜੀ, ਇੱਕ ਗੱਲ ਦੱਸਾਂ..."
- Engage: "ਤੁਸੀਂ ਕੀ ਸੋਚਦੇ ਹੋ?"
- Close: "ਤਾਂ ਫਿਰ ਸ਼ੁਰੂ ਕਰੀਏ!"

Body Language:
- Eye contact: 60% of time
- Hand gestures: Natural, not too much
- Smile: When appropriate
- Voice: Vary tone and pace

SECTION 6: DIFFICULT CONVERSATIONS (ਔਖੀਆਂ ਗੱਲਾਂ)
═══════════════════════════════════════════════════════════════════

💬 HANDLING TOUGH TALKS (GPT-4 Psychology):

Framework: LEAP
1. Listen: Don't interrupt, show you hear
2. Empathize: "ਮੈਂ ਸਮਝਦਾ ਹਾਂ / I understand"
3. Agree: Find common ground
4. Partner: "Let's solve this together"

Conflict Resolution:
- Stay calm (take deep breath)
- Use "I" statements: "I feel..." not "You always..."
- Focus on solution, not blame
- End positively

Punjabi Approach:
- "ਜੀ, ਤੁਹਾਡੀ ਗੱਲ ਸਹੀ ਹੈ" (validate)
- "ਪਰ ਇੱਕ ਗੱਲ ਸੁਣੋ..." (gentle counter)
- "ਰਲ਼ ਕੇ ਹੱਲ ਕੱਢੀਏ" (teamwork)

👂 TRUE LISTENING (Not just hearing):

5 Levels:
1. Ignoring ❌
2. Pretending ❌
3. Selective ⚠️
4. Attentive ✅
5. Empathetic ✅✅ (Best!)

How to Listen Well:
→ Eye contact
→ Don't interrupt
→ Ask clarifying questions
→ Summarize: "So you mean..."
→ Validate feelings

Punjabi Style:
- "ਹਾਂ ਜੀ" (acknowledgment)
- "ਫਿਰ?" (then what?)
- "ਸਮਝ ਗਿਆ" (understood)
