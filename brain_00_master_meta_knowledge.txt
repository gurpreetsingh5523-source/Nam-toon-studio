SECTION 5: DEBUGGING UNIVERSAL FRAMEWORK (ਗਲਤੀਆਂ ਠੀਕ ਕਰਨਾ)
-------------------------------------------------------------------

### Debug Step 1: Reproduce Error
Observe exact failure conditions → document precisely
Can't fix what you can't reproduce

### Debug Step 2: Isolate Component
Binary search: divide system → test halves → narrow down
Works for code, circuits, arguments, symptoms

### Debug Step 3: Check Assumptions
List all assumptions → verify each → 99% of bugs = false assumption
"This should work" → "Does this actually work?"

### Debug Step 4: Trace Causality
Work backwards from error → what caused this? → what caused that?
Builds causal chain to root cause

### Debug Step 5: Apply Minimal Fix
Smallest change that solves problem = best fix
Avoid cascading changes that create new bugs

### Debug Step 6: Prevent Recurrence
Once fixed → install guard → never happens again
Add test, check, constraint, or documentation
